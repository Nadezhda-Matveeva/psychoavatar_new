# Мой Аватар

Статический сайт-чек-лист для осознанного управления своим состоянием: профилактика эмоционального выгорания и ранних сигналов дисбаланса.

Сайт открывается без сборки — достаточно браузера.

## Как открыть

1. Откройте файл [`index.html`](index.html) в браузере (двойной клик или «Open with Live Server»).
2. С главной страницы перейдите в **Чек-лист** или сразу откройте [`check.html`](check.html).

Для локального сервера (по желанию):

```bash
npx --yes serve .
```

## Структура

```
аватар/
  index.html       # приветственный лендинг
  check.html       # чек-лист и калькулятор
  css/
    shared.css     # палитра, тема, навигация, кнопки
    landing.css    # стили лендинга
    check.css      # стили чек-листа
  js/
    theme.js       # светлая / тёмная тема
    check.js       # логика оценки, аватара, отчёта, истории
  images/
    avatar-excellent.webm  # зацикленное видео для уровня «Отлично»
    avatar-good.png
    avatar-medium.png
    avatar-low.png
  moi_avatar_history.html  # редирект на check.html (совместимость)
  README.md
  .gitignore
```

## Возможности

- Ежедневный чек-лист по группам: сон, питание, тело, стресс, время для себя, поддержка
- Оценка параметров по шкале **1–4**
- Аватар и рекомендации по итоговому баллу
- Красные флаги при повторяющихся «ранних сигналах»
- История и диаграмма за последние **7 дней**
- Недельный отчёт с трендом: улучшается / ухудшается / вариабельный / стабильный
- Переключение **светлой и тёмной** темы (кнопка справа внизу)

## Шкала итогового состояния

Ориентир из файла параметров (сумма приводится к шкале с максимумом 80):

| Диапазон | Уровень      | Аватар              |
|----------|--------------|---------------------|
| 70–80    | Отлично      | `avatar-excellent`  |
| 55–69    | Хорошо       | `avatar-good`       |
| 40–54    | Средний      | `avatar-medium`     |
| &lt; 40  | Критический  | `avatar-low`        |

## Данные в браузере

Всё хранится локально в `localStorage` (на сервер ничего не уходит):

| Ключ                 | Назначение                          |
|----------------------|-------------------------------------|
| `moi_avatar_history` | История прохождений и ответы        |
| `moi_avatar_theme`   | Выбранная тема (`light` / `dark`)   |

Очистка истории доступна кнопкой в чек-листе.

## Важно

Чек-лист **не для самодиагностики**, а для осознанного управления состоянием. При стойком ухудшении самочувствия обращайтесь к специалисту.
